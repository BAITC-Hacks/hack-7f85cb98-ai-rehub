# «Аким на 5 часов»

Работающий AI-симулятор управления Астаной. Пользователь собирает план из пяти разных мероприятий в пределах бюджета 100 единиц, а программа рассчитывает Astana Quality of Life Score, изменения районов и лучшую допустимую замену одного решения. AI получает только готовые результаты и объясняет их.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:4174`. Производственная сборка проверяется командой `npm run build`, расчётные тесты — `npm test`.

Есть отдельная статическая версия: `npm start` → `http://127.0.0.1:4173`. Обновлённый дизайн, выбор темы и три языка реализованы в Next.js версии на порту 4174.

## Интерфейс

Авторский интерфейс опирается на стиль [Figma-макета команды](https://www.figma.com/design/A7x3JXMIzibytFUjjHXIpM/?node-id=3-798): панель решений, итоговый Score, районы, советник и объяснение. Есть версии для рабочего стола и телефона. В верхней панели можно выбрать русский, қазақша или English и переключить светлую/тёмную тему. Эти настройки сохраняются в браузере.

Для сравнения районов выберите карточку: ниже появятся все 10 показателей с полными названиями и колонками «До / После / Изменение». Фильтр «Только изменения» скрывает неизменившиеся строки. Значения ниже 40 отмечены как критические; рост, снижение и отсутствие изменения различаются знаком и цветом. Все числа показаны до сотых, изменения рассчитаны из неокруглённых данных. Карточки не расширяются и не сдвигают соседние районы. Пока новый план не рассчитан, видны только исходные данные, а колонки результата содержат прочерки.

При первом открытии показан контрольный план M7 (Нура), M8 (Нура), M10 (Нура), M12 (город), M5 (Сарыарка). Это позволяет сразу увидеть полный сценарий. Нажмите «Изменить» в строке решения, чтобы выбрать другое мероприятие и, для районной меры, район. После изменения выполните расчёт снова. «Сохранить план» сохраняет выбор в этом браузере; «Сбросить» очищает план и сохранённую копию. Кнопка «Загрузить пример» возвращает контрольный сценарий.

Числа на Figma-макете являются иллюстрацией. Интерфейс всегда показывает значения из `calculateScenario()`. Контрольный план стоит 95 и даёт Score 56,54. Результат советника также рассчитывается кодом, поэтому его конкретная замена может отличаться от нарисованной в макете.

## Правила и расчёт

- Бюджет — не более 100 единиц.
- Ровно 5 различных мероприятий.
- Не более 2 мероприятий одного направления.
- Район обязателен для районной меры; городская действует во всех пяти районах.
- Учитываются несовместимости и синергии.
- Эффект меры с лагом `L` реализуется в доле `(8 − L) / 8`.
- Score: `0.7 × D_avg + 0.3 × min(D_d) − N_crit`.
- Критическим считается показатель строго ниже 40.

Все значения вычисляются в `src/engine.js`. `src/data.js` содержит датасет районов и мероприятий. `src/advisor.mock.js` перебирает допустимые замены одного слота. `src/i18n.ts` содержит переводы интерфейса и локального объяснения. Next.js интерфейс находится в `src/app` и `src/components`. Тесты расчётного движка — `test/engine.test.js`.

## AI-анализ

Демо работает без API: локальное объяснение строится из готового результата на выбранном языке. Если доступен backend, задайте `window.AKIM_AI_ENDPOINT` до работы интерфейса. Для русского языка клиент отправляет `POST` с результатом сценария и полем `language: "ru"`; при ошибке показывает локальное объяснение. Для казахского и английского всегда используется локальное объяснение, поэтому смена языка не оставляет русских AI-текстов. API-ключ должен храниться только на backend.

Контрольные тесты подтверждают базовый Score 52,56 и Score примера 56,54.
