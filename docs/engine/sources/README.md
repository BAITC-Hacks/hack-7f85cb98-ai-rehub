- [`dataset-ru.txt`](dataset-ru.txt) — текстовая запись исходных данных и расчётных правил; числа повторно сверены с оригинальным датасетом.
- [`tz-extracted.txt`](tz-extracted.txt) — **внутреннее шестистраничное задание участнику №1**, подготовленное при распределении работы. Это не оригинальное трёхстраничное задание организаторов. Его дополнительные требования нельзя выдавать за обязательные условия хакатона.

В оригинальном задании веса критериев: функциональность 25, техническая реализация 25, README и воспроизводимость 25, ценность 15, развитие и оригинальность 10. Ранее предоставленный отдельный скриншот содержал другую рубрику; в текущей проверке соответствия используется прикреплённый оригинальный PDF.

Набор правил не требует ровно одного решения из каждого направления: нужны пять разных мер, максимум две на направление. Это согласуется с контрольными планами оригинального датасета.
