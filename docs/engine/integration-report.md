## Независимая приёмка

Проверены исходные 50 индикаторов, цены, лаги, эффекты, отрицательный T1 у M11, три синергии и три несовместимости. Валидатор контролирует 5 различных мер, бюджет100, максимум2 одного направления, известные ID, точный scope и запрещает подмену полей. При неизвестной цене бюджет nullable. Невалидный сценарий не получает finalScore/scoreDelta и победителей советника.

При ревью найден и исправлен дефект диагностик: повторённая M4 в nura могла скрыть локальную несовместимость с M7 в nura. Автор валидатора проверяет все известные пары; в итог включены три регрессии на повторённые меры и локальные конфликты.

Evaluator проверен на отложенные эффекты, фиксированные синергии, единственный clipping после суммы, строгое `<40`, отсутствие мутаций и раннего округления. Проверены все 120 перестановок контрольного плана и дробные границы 39.999/40/40.001.

Независимый простой перечислитель проверяет реальные модули для трёх разных планов: полноту кандидатов, счётчики, top-3, все три стратегии, ASCII tie-break, ровно одну замену, воспроизведение результата и неизменность входов. Дополнительные тесты советника проверяют ничьи, пустое множество и отрицательный gain.

## Поиск и время

Один прогрев и 10 измерений на каждый план, `performance.now`, медиана как среднее 5-го и 6-го отсортированных замеров. Это локальный замер при текущей нагрузке, не SLA.

| План | Перебрано / допустимо | min / median / max, мс | Лучший Score | Gain |
| --- | ---: | ---: | ---: | ---: |
| Цена95 | 165 / 101 | 23.00 / 29.88 / 36.80 | 57.20556 | +0.66249 |
| Цена98 | 185 / 92 | 18.79 / 24.79 / 43.58 | 57.225545 | −0.01119 |

Для первого плана M5 saryarka заменяется на M3 nura, новая цена100. Для второго плана все допустимые одиночные замены хуже исходного; это не означает глобальный оптимум среди всех возможных пяти решений.

## Передача и ограничения

- Публичный API и миграция прежнего контракта: [handoff.md](handoff.md); точная схема: [parallel-contract.md](parallel-contract.md), `src/types/simulation.ts`.
- Приложение импортирует `src/domain/index.ts` либо `dist/engine/domain/index.js`. `tests/reference/engine` не подключается в production. Канонические данные находятся только в src/data.
- При объединении с Next.js сохранить scripts/dependencies приложения и добавить команды движка; автономный package.json этой ветки не заменяет package.json приложения целиком.
- UI должен проверять `valid` перед чтением чисел и форматировать значения только при выводе. AI объясняет готовые факты; contributions не следует трактовать как независимые слагаемые Score.
- Корневой README, UI, API routes и вызовы LLM не редактировались. Интегратору предстоит соединить интерфейс и AI с этим контрактом, обновить общий README и выполнить общий end-to-end сценарий.
- Реальное время окончания хакатона не предоставлено; dispatch сохраняет deadline=null. Новое пятичасовое окно не запускалось.

Материалы покрывают техническую часть критериев функциональности25, реализации25, воспроизводимости25, ценности15 и развития10. Баллы не присваиваются автоматически: они зависят от готового приложения и решения жюри.
