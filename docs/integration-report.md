## Что исправлено при объединении

- Согласованы package/lock, строгий TypeScript, ESM `.ts` импорты, alias `@`, Next config и общий тип `ScenarioResult` с `valid: true/false`.
- Frontend и AI/API переведены на `src/domain/index.ts`. Удалены старые runtime-копии frontend-данных, формул, mock-советника и статического сервера; канонический reference оставлен только в регрессионных тестах.
- UI сохранил оформление, локализации, темы, сохранение плана. AI показывает summary, факты, риски, компромиссы, рекомендации, источник, loading, ошибку и retry.
- Сервер принимает решения и пересчитывает результат. Невалидные запросы получают 400 без OpenAI. Проверяется ровно одна новая мера; перенос той же меры не проходит.
- Исправлены знаки прироста Score, минимального районного Score и числа критических показателей. Кандидаты с нулевым/отрицательным приростом допустимы.
- Применение замены меняет один слот и скрывает устаревший расчёт. Редактирование отменяет старый AI-запрос.
- В сообщениях конфликтов указаны номера несовместимых мер.
- Настроены отдельные Vitest/Node/legacy runners и общий `npm run check`, добавлены Playwright и GitHub Actions.

### Браузер

Обе ширины: официальный план → серверный fallback → лучшая замена → применение одного слота → новый расчёт; невалидный конфликт/перерасход/4 решения; городская мера без района; запрет повторного выбора; локальный максимум без улучшения; поздний AI-ответ после сброса; отказ сети с локальным анализом и успешным retry. В основном сценарии нет JS-ошибок и горизонтального переполнения. Скриншоты desktop/mobile просмотрены визуально.

Первый прогон выявил недостаточно конкретное сообщение о конфликте; добавлены ID мер. Проверка disabled у `option` уточнена до нативного DOM-свойства. Финальный прогон всех 10 тестов зелёный.

## Реальные ограничения

Синтетическая модель не прогнозирует городскую политику. Поиск ограничен одной заменой. Произвольный импорт районного датасета в UI/API не добавлялся; изменённый датасет проверен на уровне движка/AI. OpenAI участвует в русском анализе, kk/en используют локализованный детерминированный разбор. Деплой сайта не выполнялся.
